## `01 / ABOUT`

I'm **Mesa Sec**, a cybersecurity enthusiast, penetration tester, and security researcher interested in understanding how systems work, where they fail, and how those weaknesses can be responsibly identified and documented.

My interests span offensive security, web and network security, OSINT, bug bounty research, red teaming, cloud security, exploit development, social engineering, and digital forensics.

I value technical curiosity, careful investigation, reproducible research, and responsible disclosure.

## `02 / FOCUS AREAS`

- Web application and network penetration testing
- Vulnerability discovery and assessment
- Bug bounty research and responsible disclosure
- OSINT and reconnaissance
- Red team operations and authorized security simulations
- Exploit research and proof-of-concept development
- Cloud and Active Directory security assessment
- Digital forensics and network traffic analysis
- Security tooling and automation
